# engine/random

Bit-exact ports of Minecraft 1.20.6 random sources. Java `long` crosses the API as `bigint`; hot paths keep
64-bit state as int32 halves so no BigInt is touched per call.

| Export | Mirrors |
| --- | --- |
| `RandomSource`, `PositionalRandomFactory` | `net.minecraft.util.RandomSource`, `levelgen.PositionalRandomFactory` |
| `XoroshiroRandomSource`, `XoroshiroPositionalRandomFactory` | `levelgen.XoroshiroRandomSource` + `Xoroshiro128PlusPlus` |
| `LegacyRandomSource`, `LegacyPositionalRandomFactory` | `levelgen.LegacyRandomSource` + `BitRandomSource` (java.util.Random LCG) |
| `MarsagliaPolarGaussian` | `levelgen.MarsagliaPolarGaussian` |
| `mixStafford13`, `upgradeSeedTo128bit`, `seedFromHashOf` | `levelgen.RandomSupport` |
| `positionalSeed`, `positionalSeedInto` | `Mth.getSeed(int, int, int)` |
| `md5`, `sha256`, `sha256HashLong`, `javaStringHashCode` | Guava MD5 / `BiomeManager.obfuscateSeed` / `String.hashCode` |

Additions beyond Java names: `nextIntBounded` = `nextInt(bound)`, `nextIntInRange` = `nextInt(origin, bound)`,
`skip` = `consumeCount`, `PositionalRandomFactory.fromSeed(long)` = what `at()` does after computing `Mth.getSeed`.

Tests replay call sequences recorded from the real server classes (`fixtures/java-reference-vectors.json.gz`,
generated by `../noise/fixtures/ReferenceVectors.java`).
