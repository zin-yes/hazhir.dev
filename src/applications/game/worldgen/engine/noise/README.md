# engine/noise

Bit-exact ports of the Minecraft 1.20.6 noise samplers (`net.minecraft.world.level.levelgen.synth`).

| Export | Mirrors |
| --- | --- |
| `ImprovedNoise` (`noise`, `noiseWithYScale`) | `ImprovedNoise` |
| `PerlinNoise` (`create`, `createFromOctaves`, `createLegacyForBlendedNoise`, `getValue`, `getValueWithYScale`, `getOctaveNoise`, `maxBrokenValue`), `wrapNoiseCoordinate` | `PerlinNoise` |
| `NormalNoise` (`create`, `createLegacyNetherBiome`, `getValue`, `maxValue`), `NoiseParameters` | `NormalNoise` |
| `BlendedNoise` (`compute(blockX, blockY, blockZ)`, `minValue`, `maxValue`) | `BlendedNoise` (`minecraft:old_blended_noise`) |
| `SimplexNoise` (`getValue2D`, `getValue3D`), `PerlinSimplexNoise` | `SimplexNoise`, `PerlinSimplexNoise` |
| `NoiseRegistry`, `createRootRandomFactory` | the noise half of `RandomState` (`Noises.instantiate`) |

Seeding as in `RandomState` with Xoroshiro settings: root = `new XoroshiroRandomSource(seed).forkPositional()`;
each noise id is `NormalNoise.create(root.fromHashOf("namespace:path"), parameters)`; `old_blended_noise` uses
`new BlendedNoise(root.fromHashOf("minecraft:terrain"), ...)`.

Tests compare against values recorded from the real server classes for every noise in the merged vanilla +
Terralith registry at seed 1337 (`fixtures/java-reference-vectors.json.gz`, generated by `fixtures/ReferenceVectors.java`).
